# Code of Conduct

## Our commitment

We want FinEngine to be a respectful, useful, and technically serious open-source space.

Participants are expected to:
- be respectful in discussion and review
- focus on evidence and implementation quality
- welcome contributors from different backgrounds
- avoid harassment, insults, and personal attacks

## Expected behavior

- Give actionable feedback
- Critique code and ideas, not people
- Be honest about uncertainty
- Prefer clarity over hostility

## Unacceptable behavior

- Harassment or intimidation
- Hate speech or discriminatory language
- Repeated bad-faith arguments
- Publishing private information without permission

## Enforcement

Project maintainers may remove or reject content that violates this code of conduct.

## Scope

This applies to issues, pull requests, discussions, and community interactions related to this repository.
