@finengine/core

Open package docs

Money formatting, ledger validation, and debit-side aggregation for finance workflows that need deterministic checks.

import { formatMoney, validateLedgerEntry, sumEntries } from '@finengine/core'

const entry = {
  reference: 'MFS-SETTLEMENT-01',
  currency: 'BDT',
  lines: [
    { account: '1010-Cash', side: 'debit', amount: 5000 },
    { account: '2100-Customer-Balance', side: 'credit', amount: 5000 }
  ]
}

formatMoney(125000)
// BDT 125,000.00

validateLedgerEntry(entry)
// { valid: true, totalDebit: 5000, totalCredit: 5000, errors: [] }

sumEntries([entry])
// { amount: 5000, currency: 'BDT' }
  • createMoney(amount, currency?)
  • formatMoney(amount, currency?, locale?)
  • validateLedgerEntry(entry)
  • sumEntries(entries)

@finengine/math

Open package docs

EMI planning, amortization schedules, and irregular cashflow returns for lending, classroom demos, and repayment tools.

import { monthlyPayment, amortize, xirr } from '@finengine/math'

monthlyPayment(500000, 13.5, 36)
// 16967.64

const plan = amortize({ principal: 500000, annualRate: 13.5, months: 36 })
plan.totalInterest
// 110835.2
plan.schedule[0]
// { month: 1, payment: 16967.64, principalPaid: 11342.64, interestPaid: 5625, remainingBalance: 488657.36 }

xirr([
  { amount: -100000, date: '2026-01-01' },
  { amount: 25000, date: '2026-04-01' },
  { amount: 25000, date: '2026-07-01' },
  { amount: 70000, date: '2027-01-10' }
])
// 0.28
  • monthlyPayment(principal, annualRate, months)
  • amortize({ principal, annualRate, months })
  • xirr(cashflows, guess?)

@finengine/ui

Open package docs View examples gallery

UI-facing helpers that turn finance numbers into readable cards, burden labels, and learning-oriented presentation blocks.

import { amortize } from '@finengine/math'
import { makeMoneyKpi, makeRepaymentSummary, makeLearningCards } from '@finengine/ui'

const plan = amortize({ principal: 500000, annualRate: 13.5, months: 36 })

makeMoneyKpi('Monthly EMI', plan.monthlyPayment, 'SME working capital')
// { label: 'Monthly EMI', value: 'BDT 16,967.64', tone: 'positive', helper: 'SME working capital' }

makeRepaymentSummary('SME working capital', plan, 85000, 1.5).burdenLabel
// Healthy burden · 20% of income

makeLearningCards()[0].badge
// Bangladesh · intro
  • makeMoneyKpi(label, amount, helper?)
  • makeRepaymentSummary(scenario, plan, income?, feePct?)
  • makeSchedulePreview(schedule, limit?)
  • makeLearningCards()

@finengine/markets

বাংলাদেশের বিশ্ববিদ্যালয়, equity research desk, এবং asset-management training-এ DSE-compatible portfolio analytics-এর ঘাটতি পূরণ করার জন্য একটি browser-first markets engine.

  • Portfolio Variance & Sharpe Ratio Calculator: একাধিক স্টকের return এবং risk-free rate দিলে portfolio weight, variance, এবং risk-return trade-off model করবে.
  • DSE Beta & CAPM Helper: historical stock return ও market return ইনপুট থেকে beta coefficient এবং expected return estimate করবে.
  • ব্যবহারকারী: finance শিক্ষার্থী, শিক্ষক, equity analyst, এবং asset manager.
Roadmap module

@finengine/tax

NBR-facing compliance workflow-এ TDS, VDS, salary tax, rebate logic, এবং rule-based tax reasoning সহজ করার জন্য একটি programmable rules engine.

  • Invoice TDS/VDS Calculator: service বা merchant type অনুযায়ী gross amount, net payable amount, এবং challan-facing deduction breakdown দেখাবে.
  • Salary Tax Slab Parser: annual gross salary থেকে slab-wise liability, rebate, এবং step-by-step tax burden explain করবে.
  • ব্যবহারকারী: SME founder, corporate finance team, taxation শিক্ষক, এবং শিক্ষার্থী.
Replacement module

@finengine/risk

এই মডিউলটি banking, NBFI, এবং corporate lending reality-র জন্য credit risk ও financial health analytics surface দেয়.

  • Altman Z-Score (Emerging Market version): manufacturing ও non-manufacturing company data থেকে Safe, Grey, বা Distress zone classify করবে.
  • DSCR & ICR Stress Testing: income volatility-এর বিপরীতে debt-service coverage এবং interest coverage sensitivity check করবে.
  • NPL Probability Proxy: loan size, security value, এবং default depth ভিত্তিতে provisioning-margin style proxy বের করবে.
  • ব্যবহারকারী: commercial banker, credit analyst, lending instructor, এবং banking-course learner.

@finengine/corporate

Corporate-finance classroom, CFO scenario planning, এবং business-case simulation-এর জন্য valuation এবং working-capital engine.

  • Cash Conversion Cycle (CCC) Dashboard: DSO, DIO, এবং DPO input থেকে working-capital lock-up ও cashflow gap visualize করবে.
  • ব্যবহারকারী: investment-banking পরীক্ষার্থী, CFO, এবং case competition participant.

Statement-driven performance analysis-এর জন্য liquidity, profitability, efficiency, leverage, এবং DuPont decomposition engine.

Privacy posture

Local-first computation assurance

All calculations run 100% locally in your browser. No financial data is sent to external servers.

This message is especially important for teachers, researchers, bankers, and corporate users who need confidence before entering real classroom, borrower, or internal finance data.
