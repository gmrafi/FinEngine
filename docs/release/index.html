FinEngine publish checklist

Use this before publishing @finengine/core, @finengine/math, and @finengine/ui.

  1. Run npm run verify:packages locally.
  2. Check package versions, exports, README, LICENSE, and dist/ output for all three packages.
  3. Confirm live docs pages and homepage examples match the current APIs.
  4. Publish in order: @finengine/core → @finengine/math → @finengine/ui.
  5. Tag the release in GitHub and update release notes with Bangladesh finance education additions if changed.
