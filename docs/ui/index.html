@finengine/ui

UI formatting helpers and small view-model builders for FinEngine. This package bridges finance calculations and usable front-end presentation, with an eye toward Bangladesh-aware learning surfaces.

API

makeMoneyKpi(label, amount, helper?)

Returns a KPI-card-friendly view model with a formatted BDT value.

formatBurdenLabel(payment, income)

Explains repayment burden in learner-friendly language.

makeLearningBadge(topic, level)

Generates small labels for docs blocks, cards, and teaching surfaces.

Executed example

import { makeMoneyKpi, formatBurdenLabel, makeLearningBadge } from '@finengine/ui'

makeMoneyKpi('Monthly EMI', 16967.64, '36-month SME example')
// { label: 'Monthly EMI', value: 'BDT 16,968', tone: 'positive', helper: '36-month SME example' }

formatBurdenLabel(16967.64, 85000)
// Healthy burden · 20% of income

makeLearningBadge('EMI', 'intro')
// EMI · intro
