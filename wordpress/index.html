Component A · The Computational Engine

FinEngine Calculator (Plugin)

Eliminates IEEE-754 binary floating-point drift and enforces zero terminal reconciliation for all multi-year loans and financial schedules.

  • Sub-Unit Poisha Scaling: Operates strictly via integer arithmetic (1 BDT = 100 Poisha), eliminating float representation drift.
  • Terminal Zero Balance ($B_n equiv 0.00$): Enforces rigorous boundary condition so the final installment liquidates the balance to zero.
  • South Asian Numbering: Native Lakh and Crore grouping (২,৪৫,৮৭,৫০০.০০) for local banking clarity.
  • Dual Embed Options: Native Gutenberg block with InspectorControls and universal shortcode [finengine_calculator].
  • Client-Side Privacy: Zero AJAX, zero server telemetry, and zero database queries.

Mathematical Integrity

Core Architectural Guarantees for WordPress Sites

Standard web calculators rely on binary floating-point math that drifts over 36 or 60 monthly periods. FinEngine solves this natively inside WordPress:

Guarantee 01

Zero Floating-Point Drift

All currency calculations scale monetary values to integer sub-units (Poisha: 100 Poisha = 1 BDT). This eliminates the representation error inherent in JavaScript IEEE-754 double precision.

Guarantee 02

Terminal Reconciliation Rule

Multi-period amortization schedules enforce the CFSBR boundary condition: the remaining principal balance on month n liquidates cleanly to identically zero ($B_n equiv 0.00$).

Guarantee 03

South Asian Lakh/Crore Formats

Native South Asian 2,2,3 grouping (e.g., 25,00,000 for 25 Lakhs) alongside standard ISO international 3,3,3 thousands commas. Formatted smoothly across Bengali (bn-BD) and English locales.

Guarantee 04

100% Client-Side Privacy

Zero tracking, zero database writes, and zero external AJAX queries. User loan amounts and personal finance estimates remain entirely private inside the visitor browser runtime.

Guarantee 05

Dual Integration Architecture

Includes both a Full Site Editing Gutenberg Block with live sidebar InspectorControls and a universal shortcode [finengine_calculator] compatible with all page builders.

Guarantee 06

Ultra-Lightweight Performance

Zero external dependencies and no jQuery overhead. The compiled client runtime is under 25KB, achieving sub-10ms render times and flawless Google PageSpeed Core Web Vitals.

Universal Shortcode

Interactive Shortcode Generator

Configure your desired parameters below to generate a production-ready shortcode snippet for any WordPress page, post, or widget:

[finengine_calculator currency="BDT" default_principal="500000" default_rate="12.0" default_tenure="36" locale="bn-BD" primary_color="#10b981"]

Shortcode Attributes Reference

Attribute Type Default Description
currency string "BDT" ISO currency code (e.g., BDT, USD, EUR, GBP, INR).
default_principal numeric 500000 Initial principal amount loaded in the slider and numeric input.
default_rate numeric 12.0 Annual interest rate percentage loaded by default.
default_tenure integer 36 Repayment duration in months (e.g., 12, 24, 36, 60).
locale string "bn-BD" BCP 47 language tag for comma formatting and localized digits.
primary_color hex color "#10b981" Primary brand theme color applied to sliders, active tabs, and primary KPI metrics.
show_schedule boolean "true" Controls whether the month-by-month amortization schedule breakdown is rendered.
